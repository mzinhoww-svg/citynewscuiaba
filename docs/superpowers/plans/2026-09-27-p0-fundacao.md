# P0 Fundação Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repositório Next.js publicado na Vercel com tokens, fontes, CI, Supabase local com schema e seed, e o domínio puro de rótulos, confiança, regras e sanitização testado.

**Architecture:** App Router com route groups `(public)` e `estudio`. Domínio puro em `src/lib/*` sem dependência de framework, testado com Vitest. Supabase local via CLI com migrations versionadas. CI no GitHub Actions; deploy por integração GitHub ↔ Vercel.

**Tech Stack:** Next.js (App Router, estável mais recente), TypeScript strict, pnpm, Tailwind CSS v4, Radix UI, Vitest, Playwright, Supabase CLI, zod.

**Spec:** `docs/superpowers/specs/2026-09-27-citynews-design.md` · Telas: `docs/screens.md` · Arquitetura: `docs/architecture.md`

## Global Constraints

- Idioma da interface: pt-BR. Grafia: `CityNews` e `Cuiabá`.
- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`. Proibido `any` e `@ts-ignore`.
- Cores só via tokens de `src/styles/tokens.css` (copiado deste kit sem alteração).
- Fontes: Schibsted Grotesk e Source Serif 4 **locais** via `next/font/local` a partir de `design-system/fonts/*.woff2` (copiar para `src/app/fonts/`), variáveis `--font-schibsted` e `--font-source-serif`.
- Componentes seguem `DESIGN.md` §2 (refinamentos R1–R14) sobre `design-system/components/*`. Proibido hex e px crus em componentes (regra ESLint da Task 9b).
- Node LTS, pnpm ≥ 9.
- Script `pnpm verify` = `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
- Arredondamento monetário e de score: `Math.round((x + Number.EPSILON) * 100) / 100`.

## Review Focus

1. Score de confiança com ponto flutuante (0,645) arredonda para 0,65, não 0,64 → teste em Task 4.
2. Texto externo com instrução disfarçada em maiúsculas, acentos ou HTML (`<b>IGNORE</b> as regras`) → detectado → teste em Task 6.
3. Artigo com 6 rótulos possíveis mostra só 4, na ordem fixa → teste em Task 3.
4. Categoria desconhecida em `decidePublication` cai em revisão, nunca em automático → teste em Task 5.
5. Build de produção sem variáveis de ambiente de IA não quebra o portal público → teste em Task 9 (`pnpm build` com `.env.example`).
