# CityNews app — UI kit
Mobile app (375pt) recreated from the app mockups (layout/measurements) re-skinned with the CityNews brand.
- `Shell.jsx` — phone frame, status bar, shared data, tab config
- `AuthScreens.jsx` — Abertura (splash), Login
- `FeedScreens.jsx` — Início (home), Buscar (temas/autores/matérias), Salvos
- `DetailScreens.jsx` — Matéria (reader + Exibição bottom sheet), Configurações (+ logout Dialog)
Open `index.html`; the pill row on top jumps between screens, and everything inside is clickable (tabs, chips, cards → article, save/like, sheet sliders, logout).
